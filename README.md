## Overview

`@qmoosa/pqc-mlkem-dashboard` provides the interactive Web4 inspection terminal, telemetry monitor, and entropy evaluator for post-quantum cryptographic sessions across the QMOOSA-1000 portfolio (Domain 2: Post-Quantum Cryptography & Quantum Security, Batch 11, Repository 054).

---

## Features

- **Entropy Quality Monitor**: Evaluates Shannon entropy, min-entropy, and chi-squared test statistics on cryptographic seeds.
- **Handshake Telemetry Simulator**: Real-time simulation of pure and hybrid ML-KEM key encapsulations with latency and verification metrics.
- **NIST FIPS 203 Parameter Registry**: Interactive comparison of ML-KEM-512, ML-KEM-768, and ML-KEM-1024 dimensional characteristics.
- **Responsive Terminal UI**: Pure HTML/CSS dark cyber-terminal dashboard.
